## Resumen rápido del turno

```
1. Inicio del turno
2. Fase de Mando      → 1 PM básico por jugador + acobardamiento
3. Fase de Movimiento → normal / avanzar / retroceder
4. Fase de Disparo    → normal / asalto / quemarropa / indirecto
5. Fase de Carga      → declarar → tirar 2D6 → mover → Combatir primero
6. Fase de Combate    → agruparse → combatir (primero primero, luego resto) → consolidar
7. Final del turno
```

## Tabla para herir — F vs R

| Condición | Mínimo |
|-----------|--------|
| F ≥ 2×R | 2+ |
| F > R | 3+ |
| F = R | 4+ |
| F < R | 5+ |
| F ≤ R÷2 | 6+ |

> **1 sin modificar** = fallo siempre · **6 sin modificar** = impacto/herida crítica
